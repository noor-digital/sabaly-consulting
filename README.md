# Sabaly Consulting — site vitrine

Site vitrine statique en français pour présenter Sabaly Consulting, ses services, ses programmes et ses références.

## Aperçu

Version de démonstration du site composée de pages HTML, de styles CSS personnalisés et de JavaScript côté navigateur.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.8 (chargé depuis jsDelivr)
- Bootstrap Icons et Font Awesome (chargés depuis leurs CDN)
- JavaScript natif

## Lancer le projet en local

Aucun serveur PHP ou installation de dépendances n'est nécessaire. Ouvrez `index.html` dans un navigateur ou utilisez l'extension Live Server de Visual Studio Code. Une connexion Internet est nécessaire pour charger les bibliothèques et les polices/icônes servies par CDN.

## Pages

- `index.html` — accueil
- `apropos.html` — à propos
- `services.html` — services
- `programme.html` — programmes
- `reference.html` — références

## Formulaire de contact

Le projet est statique et ne possède pas de backend. Le formulaire prépare un message via `mailto:` et demande à l'utilisateur de l'envoyer depuis son application de messagerie. L'envoi dépend donc de la configuration de cette application. Pour un envoi fiable sans client e-mail local, il faudra intégrer un backend ou un service de formulaire autorisé par le propriétaire du site.

- Vérifiez que vous êtes autorisé à publier le code source et les images/logos appartenant à Sabaly Consulting ou à ses partenaires.
